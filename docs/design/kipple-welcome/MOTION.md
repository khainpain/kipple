# Движение

Kipple двигается тепло и коротко, с лёгкой пружинкой. Движение что-то объясняет (откуда появилось, что изменилось, что было принято) и никогда не тянет на себя внимание. Все анимации взяты из одного набора: **React Bits** (reactbits.dev, лицензия MIT + Commons Clause, в приложении использовать можно). Неон, WebGL-фоны, курсоры-эффекты и глитч-тексты не используем: они не подходят тёплой бумаге и коралловому акценту.

## Как подключить

React Bits раздаётся через реестр shadcn. В проекте один раз:

```
npx shadcn@latest mcp init --client claude
```

В `components.json` добавить реестр `"@react-bits": "https://reactbits.dev/r/{name}.json"`, затем ставить компоненты по одному: `npx shadcn@latest add @react-bits/BlurText-TS-CSS` (имя = `Компонент-ЯЗЫК-СТИЛЬ`; у Kipple TypeScript и обычный CSS, значит всегда `-TS-CSS`). Компоненты копируются в код. Зависимость одна, **motion** (`motion/react`). Компоненты на GSAP не берём, чтобы не тащить вторую анимационную библиотеку.

## Кривые и время

| Токен | Значение | Где |
| --- | --- | --- |
| `ease-out` | `cubic-bezier(.22, 1, .36, 1)` | появление, сдвиги, слайды |
| `ease-spring` | `cubic-bezier(.34, 1.56, .64, 1)` | переключатели, наведение на карточки |
| `duration-micro` | 150–200 мс | нажатие, наведение |
| `duration-ui` | 300–450 мс | переключатели, слайд экранов, тост |
| `duration-enter` | 600–800 мс | первое появление экрана |
| `stagger` | 60–80 мс | шаг между элементами списка или блока |

Всё выключается при `prefers-reduced-motion: reduce`: элементы сразу стоят на месте, пасхалки не срабатывают.

## Набор компонентов

| Задача | Компонент React Bits | Настройки Kipple |
| --- | --- | --- |
| Заголовок экрана | **BlurText** | по словам, direction `top`, delay 80 мс, stepDuration .35 |
| Появление блоков | **AnimatedContent** (вариант на motion) / FadeContent | distance 18px, duration .8, stagger 80 мс |
| Списки (шаги экспорта, выдача поиска) | **AnimatedList** | появление снизу 14px + scale .96, шаг 60 мс |
| Коллаж и стопки карточек | **BounceCards** | bounciness .6, stagger .06, hoverScale 1.06, без белой рамки (`borderWidth 0`), radius 12 |
| Доска | **Masonry** | появление карточек снизу, stagger 50 мс, hover = текущий `shadow-hover` + подъём на 2px |
| Отклик на нажатие (маскот, главная кнопка) | **ClickSpark** | 8 искр, radius 36, duration 550 мс, цвета `accent` и `#F2A58F` |
| Переключатели | **SquishSwitch** | 44×26, дорожка `accent` / `rgba(ink, .22)`, бегунок `panel`, stretch 36 |
| Галочки | **SpringCheck** | цвет `accent` |
| Необратимые действия («Удалить все данные») | **HoldButton** | holdTime 1600 мс, заливка `danger`, текст «Удерживай, чтобы удалить» → «Удалено» |
| Тосты | **SwipeToast** | фон `ink`, текст `bg`, смахивается вбок |
| Статусы («Сохранён», «Вход выполнен») | **StatusMark** | цвет `ok` |
| Шаги входа | **Stepper** | только индикатор; активный шаг `accent` |

## Своё, поверх набора

- **Маскот**: покачивание 4,8 с, двойное моргание раз в 5,2 с, сальто на 7-е нажатие подряд, злость на 13-е. В ключевых кадрах сальто во всех кадрах одинаковый набор трансформаций, иначе поворот режется.
- **Парение карточек в коллаже**: у каждой свой рисунок движения и период (5,3 / 6,7 / 8,6 / 9,7 с), чтобы они не шли в такт.
- **Слайд между экранами** (вход ↔ экспорт): сдвиг дорожки на 50% за 450 мс `ease-out`, уходящий экран гаснет.

Живые примеры смотри на канвасе Kipple, артборды «Приветствие» и «Настройки», режим Play.
